# CasaCraft + GitHub Actions

1. Crea un repositorio en GitHub y sube todos los archivos de este proyecto.
2. Abre Actions.
3. Selecciona "Build CasaCraft APK".
4. Pulsa "Run workflow".
5. Cuando termine correctamente, abre la ejecución y descarga "CasaCraft-debug-apk".
6. El archivo contiene app-debug.apk.

Este flujo compila la app en un runner de GitHub y guarda la APK como artifact.
